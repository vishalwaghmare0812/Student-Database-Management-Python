# Student Management System

A web-based application built with Python, Flask, and SQLite to efficiently manage student records.

## Features
- Add, view, update, and delete student records.
- Search students by roll number, name, email, or course.
- Input validation and duplicate roll number prevention.
- Persistent data storage using SQLite.

## Technologies Used
- Python
- Flask
- SQLite
- HTML, CSS
